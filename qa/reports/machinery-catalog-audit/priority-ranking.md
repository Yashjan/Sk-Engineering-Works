## Recommended next three

### 1. ID Fan / Blower — ready for conservative content improvements

**Why:** It connects the drying and air-handling system to a commercially meaningful equipment enquiry, and it has the strongest remaining evidence set.

**Improve:** distinguish induced-draft fan vs generic blower terminology; explain fan-system duty conservatively; add actual visible components; replace shared configuration rows with airflow/static-pressure, gas/air condition, duct, drive and installation inputs; connect neutral workshop/project records; add machine-specific metadata and dedicated Hindi/Arabic copy.

**Engineering evidence required:** fan type; impeller arrangement; direction of flow/rotation; design airflow and static pressure selection process; temperature and particulate conditions; drive/coupling arrangement; casing/impeller material options; balancing/testing records; exact identity of the media unit.

**SEO opportunity:** qualitative intent around industrial ID fan/blower for salt dryer and process-air systems. Link from Dryer, Cyclone, Bag Filter, Salt Refinery Plants and the existing equipment project record.

**Complexity:** Medium. The shared detail structure exists and media is present; technical verification and localization are the main work.

### 2. Cyclone — ready for conservative content improvements after provenance check

**Why:** It is already part of the published refinery process and has fabrication/completed-machine footage. It can explain the relationship between particle separation, the fan and downstream collection without unsupported performance claims.

**Improve:** explain tangential inlet/separation/discharge only if the supplied geometry confirms it; add system boundaries and enquiry inputs; surface project media neutrally; replace generic metadata; add dedicated translations and contextual links.

**Engineering evidence required:** actual inlet/body/outlet geometry; whether units are single or multiple; design airflow and particle data used for selection; pressure-drop basis; discharge/airlock arrangement; material/lining options; connection to fan/bag filter; confirmation that `plant-structure.webp` depicts this cyclone installation.

**SEO opportunity:** qualitative intent around industrial cyclone separator for salt/process-air dust separation. Link from Dryer, ID Fan / Blower, Bag Filter, Pin Mill and Complete Salt Refinery Plants.

**Complexity:** Medium. Media and route exist; exact system claims and image provenance are the constraints.

### 3. Dryer — needs engineering verification first

**Why:** Drying is a core stage between dewatering and downstream handling. A credible page can support complete-plant enquiries more directly than peripheral equipment, but the current evidence does not identify the dryer technology.

**Improve:** name the actual dryer type only after confirmation; explain material/air path, heat source, feed/discharge, moisture-control inputs, exhaust handling, installation and enquiry data; add dedicated localized SEO and technical translations; link to Centrifuge, Screw Conveyor, ID Fan / Blower, Cyclone and Bucket Elevator.

**Engineering evidence required:** dryer type and internal arrangement; heat source; direct/indirect contact; airflow direction; feed/discharge controls; inlet/outlet moisture range used for selection (not public performance guarantees); temperature/control/safety philosophy; exhaust and dust handling; construction options; real unit photos/drawings and delivered-project provenance.

**SEO opportunity:** qualitative high-intent searches around industrial salt drying equipment and refinery drying systems. No measured keyword-volume claim is made.

**Complexity:** High. Repository structure is ready, but reliable content cannot be completed from the render and generic copy alone.
