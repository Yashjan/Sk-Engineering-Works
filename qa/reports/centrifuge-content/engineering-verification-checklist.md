# Centrifuge engineering-verification checklist

The public page intentionally withholds the following information until supported by approved company records.

| Item requiring confirmation | Required record |
|---|---|
| Actual centrifuge type and intended applications | Approved product specification |
| Internal rotor, basket, scroll, screen, cloth or other separation mechanism | Section drawing or approved GA |
| Continuous or batch operating mode and discharge cycle | Operating sequence |
| Feed, liquid outlet and solids-discharge arrangements | Process and connection drawing |
| Capacity, feed variation and operating hours | Duty sheet |
| Feed particle size and inlet moisture | Process requirement |
| Expected discharge condition or moisture | Test basis and applicable feed conditions |
| Rotational speed, motor rating and transmission | Drive schedule |
| Shaft, bearings, seals, lubrication and vibration control | Mechanical drawing |
| Rotor or basket dimensions and overall machine dimensions | Approved GA |
| Materials, surface protection and wear provisions | Material specification |
| Foundation, support loads, installation and electrical requirements | Site interface drawing |
| Guarding, inspection, cleaning and maintenance provisions | Safety and maintenance documentation |
| Applicable engineering and safety standards | Approved compliance record |
| Machine-only, installation, controls and commissioning scope | Commercial scope |
| Centrifuge-specific fabrication, installation and project associations | Traceable media and project records |

Do not publish RPM, TPH, motor power, moisture reduction, residual moisture, purity, separation efficiency, energy savings, yield, life, warranty, delivery time or customer claims without documented confirmation.
